✦ Project Overview

NOIRE is a fashion e-commerce concept that combines editorial fashion discovery with an intuitive shopping experience.

Users can explore fashion through style-based onboarding, browse curated products, view product details, add items to their bag, complete checkout, and receive an order confirmation.

✦ Key Features
Style-based onboarding
Editorial fashion homepage
Curated product discovery
Product filtering
Product detail page
Colour and size selection
Wishlist interaction
Shopping bag
